# Файловые системы и конфигурация

## VFS

VFS API объявлен в `kernel/includes/fs.h`, маршрутизация реализована в `kernel/filesystems/fs.c`. `FileSystem` хранит mountpoint, driver, block device и private state. Путь нормализуется и передаётся драйверу относительно точки монтирования.

Основные операции:

- файлы: open/read/write/seek/close;
- каталоги: opendir/readdir/closedir;
- изменения: mkdir/unlink/rmdir/rmdir_r.

Syscall слой копирует user pointers в kernel memory/проверяет user ranges, прежде чем передавать данные VFS.

## FAT32

FAT32 драйвер расположен в `kernel/filesystems/fat32.c`. Он обслуживает корневую файловую систему и операции с кластерами, каталогами и файлами. FAT32 directory entries фильтруют удалённые записи, LFN records и volume labels; имена преобразуются в строковый формат для VFS.

Текущий `fat32_readdir(dir_cluster, index)` ищет запись по номеру, каждый раз начиная обход с начала каталога. Повторный запрос последовательных индексов может повторно читать одни и те же кластеры. Для больших каталогов правильный следующий шаг — хранить итератор/позицию в `File.private` и читать последовательно.

## regfs и hive

regfs — реестр, смонтированный в `/reg`. Hive загружается из `/reg/SYSTEM.HIV`; `config_load()` переносит значения в структуру `SystemConfig`. Конфигурационные ветви перечислены в `kernel/includes/config.h` и отражены в `tools/SYSTEM.ini`.

`tools/hivegen.py` преобразует INI в бинарный hive. Команда `make config-hive` генерирует hive и копирует его в `disk.img`. Если regfs не смонтирован или hive некорректен, ядро использует значения по умолчанию; без синхронизации изменения реестра могут потеряться при выключении.

## tmpfs и block cache

tmpfs предоставляет временное файловое пространство без сохранения после выключения. Block cache хранит недавно прочитанные блоки и снижает повторный ввод-вывод с NVMe/FAT32.

## Пользовательские файловые вызовы

Приложения используют обёртки в `user/sys.h`: `sys_open`, `sys_read`, `sys_write`, `sys_close`, `sys_opendir`, `sys_readdir`, `sys_mkdir`, `sys_unlink` и `sys_rmdir`. Права доступа задаются `FS_READ`, `FS_WRITE`, `FS_CREATE`, `FS_APPEND` и `FS_TRUNCATE`.
